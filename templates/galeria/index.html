About the Project

Our molecular database is a tool to advance the fight against leishmaniasis, a neglected tropical disease that affects millions globally. This project provides a broad collection of molecules, allowing users to explore, visualize, and compare data based on 2D Tanimoto similarity and robust 3D shape alignment using LS-align and RDKit.
